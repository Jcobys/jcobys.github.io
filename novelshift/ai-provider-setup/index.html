Set up your AI API key

Choose a provider, create an API key on its official site, then return to NovelShift to paste and test it. Third-party sign-in and payments are completed in your system browser.

Keep your API key safe

Only paste your key inside NovelShift settings. Never send it in a message, email, screenshot, or third-party form. NovelShift will never ask for your complete key.

Before you begin
  • • Provider websites, availability, regions, and billing rules may change. Follow the provider’s current official instructions.

API Key Setup

OpenAI

OpenAI API Platform

Open official key page
  1. 1

    Open the API Platform

    Sign in with your OpenAI account. ChatGPT subscriptions and API usage are billed separately.

  2. 2

    Create a secret key

    On the API Keys page, select “Create new secret key”. You can name it NovelShift.

  3. 3

    Copy the complete key

    Copy and store it securely right away. The full secret key is normally shown only once.

  4. 4

    Return to NovelShift

    Paste the key, select a model, then choose Save & Test.

API Key Setup

Tencent Hunyuan

Connected through Tencent Cloud TokenHub

Open official key page
  1. 1

    Choose a service region first

    In NovelShift, choose Mainland China (Guangzhou) or International (Singapore). Use the same region when you create the key.

  2. 2

    Sign in and enable TokenHub

    First-time users may need a Tencent Cloud account, identity verification, or service activation.

  3. 3

    Confirm the region and model

    Choose the same region in TokenHub. If needed, enable your Hunyuan model from the model marketplace.

  4. 4

    Create and copy an API key

    Create a key in API Key Management, name it NovelShift if you like, then copy the complete key.

  5. 5

    Return to NovelShift to test

    Confirm the region matches the one used to create the key, then paste it and test the connection.

Your Key and region must match. Mainland China (Guangzhou) uses tokenhub.tencentmaas.com/v1; International (Singapore) uses tokenhub-intl.tencentmaas.com/v1.

API Key Setup

Google Gemini

Google AI Studio

Open official key page
  1. 1

    Open Google AI Studio

    Sign in with your Google account. Accept any required terms on the official page.

  2. 2

    Find or create an API key

    You may already have a default project and key. Otherwise, select “Create API key” and follow the prompts.

  3. 3

    Use a current Auth Key

    Create a current key in AI Studio instead of relying on an older unrestricted Standard Key.

  4. 4

    Return to NovelShift

    Copy the API key, return to the app, select a model, and choose Save & Test.

Availability, regions, and quotas are determined by Google. If Google says the service is unavailable in your region, choose another provider; NovelShift does not bypass regional restrictions.

API Key Setup

Claude

Provided by Anthropic

Open official key page
  1. 1

    Open Claude Platform

    Sign in with Google, email, or SSO. First-time users may need to complete organization or use-case setup.

  2. 2

    Check API credits

    Claude chat subscriptions are different from API credits. If needed, buy credits on the Billing page.

  3. 3

    Create an API key

    On the API Keys page, select “Create Key”. If prompted, most individuals can use Default Workspace.

  4. 4

    Return to NovelShift

    Copy the new key, paste it in the app, select a model, and choose Save & Test.
