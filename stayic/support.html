Keyboard / 键盘

Enable StayIC in iOS Settings → General → Keyboard → Keyboards. Cloud checks in the keyboard require Full Access; local typing does not require cloud AI. Secure fields and some apps use the system keyboard. / 在 iOS 设置 → 通用 → 键盘 → 键盘中添加 StayIC。键盘内云端检查需要完全访问，本地输入无需云端 AI。安全输入框及部分 App 使用系统键盘。
